# Правила розробки проєкту
1. Дотримуватися єдиного стилю написання коду.
2. Писати змістовні повідомлення до кожного коміту.
3. Перевіряти статус файлів командою git status перед фіксацією.
4. Не додавати тимчасові файли та логи до індексу.
5. Проводити тестування перед злиттям змін в основну гілку.
